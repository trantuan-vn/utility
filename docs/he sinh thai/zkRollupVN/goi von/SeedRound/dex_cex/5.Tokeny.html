Uniswap Interface + Tokeny (T-REX & ERC-3643)

Tài liệu này chứa sơ đồ mermaid (rendered) và giải thích ngắn gọn bằng tiếng Việt về các thành phần: T-REX, ERC-3643 (EIP-3643), uniswap-v2-sdk-trex, và uniswap-interface.

Giải thích các thành phần (tóm tắt)

T-REX (Tokeny)

T-REX là bộ hợp đồng thông minh do Tokeny cung cấp để phát hành, quản lý token chứng khoán (security tokens). Thông thường bao gồm:

  • Token Agent / Token Factory: triển khai token mới theo chuẩn ERC-3643 hoặc các chuẩn tuỳ biến.
  • Identity Registry: danh sách địa chỉ đã được KYC/AML — dùng để whitelist/blacklist.
  • Transfer Manager / Compliance Engine: áp quy tắc chuyển nhượng (ví dụ: chỉ cho chuyển giữa các địa chỉ đã KYC, giới hạn số lượng, hạn chế theo quốc gia...)

EIP-3643 (ERC-3643)

ERC-3643 (EIP-3643) là một tiêu chuẩn token để hỗ trợ security tokens với tính năng quản lý danh tính và tuân thủ. Điểm chính:

  • Hỗ trợ Identity Registry để kiểm tra KYC trước khi chuyển token.
  • Cung cấp hooks để gọi transfer checks trước khi thực hiện chuyển.
  • Thiết kế để tích hợp dễ với off-chain KYC providers và on-chain registry.

uniswap-v2-sdk-trex

Đây là phần mở rộng / helper (không chính thức trong mọi repo) — ý tưởng là có một lớp SDK hoặc adapter cho Uniswap V2/Uniswap SDK để:

  • Hiểu các token ERC-3643 (ví dụ: check cần approve đặc biệt, hoặc cần whitelist check trước khi swap).
  • Tự động gọi các check/approve cần thiết với T-REX contracts trước khi thực hiện swap.
  • Kết hợp với UI để hiển thị lý do nếu giao dịch không thể thực hiện vì chính sách compliance.

Uniswap Interface

Giao diện frontend chính (React / Next.js) mà người dùng tương tác. Vai trò liên quan Tokeny:

  • Hiển thị token list (có thể bao gồm security token từ Tokeny/T-REX).
  • Sử dụng SDK để tính route và tạo tx. Nếu token là ERC-3643, UI/SDK cần gọi các contract compliance/registry trước khi emit tx.
  • Thông báo cho người dùng nếu token không thể chuyển do không KYC, hoặc do rule.

Flow ví dụ khi người dùng bấm "Swap" token ERC-3643

  1. UI gọi SDK để tính toán trade và kiểm tra cần thiết.
  2. SDK (hoặc adapter uniswap-v2-sdk-trex) kiểm tra IdentityRegistry xem cả hai địa chỉ (người gửi & recipient của pool) đã được whitelist chưa.
  3. Nếu cần, SDK yêu cầu người dùng thực hiện steps: đăng ký KYC, approve token, hoặc mint token agent call.
  4. Khi mọi checks pass, UI gửi tx (ký bởi ví) để tương tác với Uniswap pool hoặc trực tiếp transfer token qua ERC-3643 (tùy flow).
  5. Smart contract ERC-3643 gọi Compliance Engine/Identity Registry trong quá trình transfer để xác nhận giao dịch hợp lệ.
  6. Giao dịch hoàn tất on-chain; UI nhận receipt qua RPC và hiển thị kết quả.

Ghi chú & Tài liệu tham khảo

  • Repo Tokeny thường chứa hợp đồng T-REX, Identity Registry và ví dụ tích hợp ERC-3643.
  • EIP-3643: mô tả chi tiết interface token security với hooks cho compliance.
  • uniswap-interface & uniswap SDK repos: tham khảo cách SDK tạo trade và transaction data.
