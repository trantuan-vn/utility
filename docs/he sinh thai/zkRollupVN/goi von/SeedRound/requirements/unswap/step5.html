Phân Tích Bước 5: Integrations Web3, API, GraphQL Uniswap Interface

Dựa trên cấu trúc thư mục từ file structure.txt, bước này phân tích sâu cách Uniswap interface tích hợp blockchain (Web3 qua Wagmi, Ethers.js), GraphQL (Apollo Client), và API (serverless functions). Integrations kết nối frontend (React UI) với blockchain/external services, đảm bảo dữ liệu real-time (prices, pools) và giao dịch (swaps, liquidity).

Mục Tiêu Chi Tiết

  • Hiểu Web3 integration: Kết nối wallet (Wagmi), smart contracts (Ethers.js), blockchain data (timestamps, gas).
  • Hiểu GraphQL integration: Apollo Client query Uniswap subgraph (pools, tokens, ticks).
  • Hiểu API integration: Serverless functions (Cloudflare/Vercel) cho images, routing, caching.
  • Nắm data flow: UI -> hooks (Web3/GraphQL) -> API/blockchain -> render (charts, modals).
  • Lý do quan trọng: Kết nối state (Bước 2), UI (Bước 3-4) với blockchain/services. Giúp debug tx failures, slow queries.

Hành Động Cụ Thể Và Hướng Dẫn Thực Hiện

1. Tập Trung Vào Web3 Integration (src/connection/)

  • Xem files:
    • wagmiConfig.ts: Config Wagmi client (chains, connectors).
    • EmbeddedWalletConnector.ts, InjectedConnector.ts, SafeAppConnector.ts: Wallet connectors.
    • hooks/useConnect.tsx, useDisconnect.ts: Connect/disconnect hooks.
    • useEthersProvider.ts, useEthersSigner.ts: Ethers.js providers/signers.
  • Sâu hơn:
    • Wagmi setup chains (Ethereum, Polygon) và connectors (MetaMask, WalletConnect).
    • useContract.ts gọi smart contracts (e.g., UniswapV3Pool.sol).
    • useTransactionGasFee.ts tính gas, tích hợp state/routing/.
  • Hướng dẫn: Mở wagmiConfig.ts, tìm createConfig. Chạy app, dùng devtools để inspect wallet connection (Network tab).

2. Tập Trung Vào GraphQL Integration (src/appGraphql/)

  • Xem files:
    • apollo/client.ts: Apollo Client setup.
    • data/Token.ts, data/pools/PoolData.ts: Queries.
    • pools/usePoolData.ts, usePoolPriceChartData.tsx: Hooks.
  • Sâu hơn:
    • AllV3TicksQuery.ts: Tick data cho charts.
    • Apollo cache optimize queries, persist qua PersistQueryClient.tsx.
    • Error handling trong usePoolData.ts.
  • Hướng dẫn: Mở apollo/client.ts, tìm new ApolloClient. Dùng Apollo DevTools để inspect queries (PoolDetails page).

3. Tập Trung Vào API Integration (functions/)

  • Xem files:
    • api/image/: Image generation (tokens, pools).
    • explore/getToken.ts, getPool.ts: Token/pool data.
    • utils/cache.ts: Caching.
  • Sâu hơn:
    • Serverless functions (Cloudflare/Vercel) handle non-blockchain tasks.
    • routing/client.ts gọi routing API (UniswapX).
    • Tests (*.test.ts) verify responses.
  • Hướng dẫn: Mở functions/api/image/, tìm handler. Chạy npm run dev để test locally.

4. Trace Data Flow

  • UI: PoolDetails.tsx gọi usePoolTickData.ts -> query data/pools/.
  • Web3: ConfirmSwapModal.tsx dùng useSwapCallback.tsx -> useContract.ts.
  • API: PortfolioLogo.tsx load images từ functions/api/image/.
  • Hướng dẫn: Tìm "useQuery" (GraphQL) hoặc "useContract" (Web3). Console.log trong hooks.

Mô Tả Chi Tiết Thư Mục src/connection/, src/appGraphql/, functions/

src/connection/

  • EmbeddedWalletConnector.ts: Uniswap wallet.
  • InjectedConnector.ts: MetaMask.
  • SafeAppConnector.ts: Safe wallet.
  • UniswapExtensionWalletConnector.ts: Extension wallet.
  • wagmiConfig.ts: Wagmi config (chains, connectors).
  • types.ts: Types.

src/appGraphql/

  • apollo/:
    • client.ts: Apollo Client setup.
    • client.test.ts: Tests.
  • data/:
    • Pool.ts, PoolData.ts, Token.ts, TokenPrice.ts: Queries.
    • AllV3TicksQuery.ts, PoolDayDataQuery.ts: Tick/day data.
    • gql/: GQL queries (e.g., PoolDayData.graphql).
  • pools/:
    • usePoolData.ts, usePoolPriceChartData.tsx: Hooks.
    • PoolChartDataProvider.tsx: Data provider.
  • tokens/:
    • useTokenData.ts: Token hooks.
  • utils/:
    • useGraphqlRequest.ts: Request wrapper.
    • utils.ts: Query utils.

functions/

  • api/:
    • image/: generatePoolImage.ts, generateTokenImage.ts, getToken.ts.
    • metadata/, robots/: SEO, robots.txt.
  • explore/:
    • getPool.ts, getToken.ts: Pool/token data.
  • utils/:
    • cache.ts: Caching.
    • getToken.ts: Token utils.
  • babel.config.js, tsconfig.json: Config.
  • tests/: Tests (e.g., generatePoolImage.test.ts).

Mối Liên Hệ Giữa Các File Và Thư Mục

  • Web3 -> Components/Hooks: useEthersProvider.ts cung cấp provider cho useContract.ts, dùng trong ConfirmSwapModal.tsx.
  • GraphQL -> Pages: PoolDetails.tsx dùng usePoolData.ts -> query data/Pool.ts.
  • API -> Components: PortfolioLogo.tsx load images từ functions/api/image/.
  • Hooks -> Integrations: useSwapCallback.tsx dùng wagmiConfig.ts, routing/client.ts.
  • State -> Integrations: state/swap/ dispatch actions gọi sagas (sagas/transactions/swapSaga.ts), dùng Web3/GraphQL.
  • Tests: playwright/mocks/ mock GraphQL, connection/*.test.ts mock wallets.
