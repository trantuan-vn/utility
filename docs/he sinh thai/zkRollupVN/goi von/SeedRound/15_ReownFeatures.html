Giới thiệu 3 Tính năng chính tích hợp Reown

Kết nối ví • Mua crypto • Swap — kèm sơ đồ luồng (Mermaid) và mô tả chi tiết.

1. Kết nối ví (Connect Wallet)

Luồng kết nối ví khi DApp tích hợp Reown SDK (WalletConnect). Reown là lớp trung gian giúp DApp và ví giao tiếp — session keys, QR/deeplink, user approval.

%%{init:{"theme":"default"}}%% sequenceDiagram participant User participant Client participant Backend participant Wallet User->>Client: Mở dApp, chọn "Connect Wallet" Client->>Wallet: Mở modal Reown, user chọn ví, kết nối Wallet->>Client: Trả về địa chỉ ví (address) Client->>Backend: Yêu cầu challenge (nonce) kèm địa chỉ ví Backend->>Client: Trả về message challenge Client->>Wallet: Yêu cầu ký message challenge Wallet->>User: Hiển thị prompt ký User->>Wallet: Ký message, trả về chữ ký Wallet->>Client: Trả chữ ký Client->>Backend: Gửi địa chỉ ví + chữ ký để xác thực Backend->>Backend: Verify chữ ký hợp lệ alt Nếu hợp lệ Backend->>Client: Tạo session, set HttpOnly cookie Client->>User: Hiển thị trạng thái đăng nhập else Nếu không hợp lệ Backend->>Client: Trả lỗi xác thực end Note over Client,Backend: Các request API tiếp theo từ client sẽ kèm cookie để xác thực phiên Client->>Backend: Gọi API cần bảo mật (ví dụ lấy dữ liệu cá nhân) Backend->>Backend: Xác thực session từ cookie Backend->>Client: Trả dữ liệu Client->>Wallet: Khi user gửi giao dịch blockchain (swap, chuyển token) Wallet->>User: Hiển thị prompt ký giao dịch User->>Wallet: Ký giao dịch Wallet->>Blockchain: Gửi giao dịch lên blockchain
Ghi chú: Session key có thể lưu trên Reown Cloud hoặc backend của bạn.

2. Mua Crypto (Buy — On-Ramp)

Flow mua crypto (fiat → crypto) tích hợp Reown/AppKit Pay + Meld/on-ramp provider.

%%{init:{"theme":"default"}}%% sequenceDiagram participant U as 🧑 User participant D as 🌐 DApp participant W as 💼 Wallet participant R as 💳 On-Ramp Provider participant P as 🏦 Payment Gateway participant B as ⛓ Blockchain participant L as 💧 Liquidity Pool U->>D: Chọn Buy Crypto D->>W: Yêu cầu kết nối ví W-->>U: Xác nhận kết nối U-->>W: Đồng ý D->>R: Gửi thông tin đơn hàng R->>P: Điều hướng thanh toán U-->>P: Thanh toán P-->>R: Xác nhận thành công R->>B: Gửi giao dịch mua token B->>L: Swap/mint token L-->>B: Cung cấp token B-->>W: Token về ví user
Ghi chú: Provider thu phí, bạn có thể nhận commission nếu có hợp đồng affiliate.

3. Swap (Token A → Token B)

Luồng swap: Reown lấy quote từ 1inch, tạo calldata cho router contract, user ký và gửi tx.

%%{init:{"theme":"default"}}%% sequenceDiagram autonumber participant U as User participant WA as Web App participant WC as Reown SDK participant QC as Quote API participant SC as Smart Contract participant BC as Blockchain participant LP as Liquidity Pool U->>WA: Chọn tokenA → tokenB WA->>QC: Gọi quote API QC-->>WA: Trả quote + calldata U->>WC: Connect wallet WC-->>WA: Trả address alt Cần approve U->>WA: Click Approve WA->>WC: Gửi approve tx WC->>BC: Broadcast BC-->>WC: Tx mined end U->>WA: Click Swap WA->>WC: Ký & gửi swap tx WC->>SC: Broadcast SC->>LP: Swap tokenA → tokenB LP-->>SC: Trả tokenB SC->>BC: Hoàn tất tx BC-->>WA: Notify kết quả WA-->>U: Hiển thị kết quả
Ghi chú: Reown không giữ token; swap diễn ra trên DEX/aggregator contract.
