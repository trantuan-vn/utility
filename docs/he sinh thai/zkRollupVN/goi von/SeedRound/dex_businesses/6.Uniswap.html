Giới Thiệu Toàn Diện Về Uniswap

1. Tổng Quan Về Uniswap

Uniswap là một giao thức trao đổi phi tập trung (DEX) chạy trên Ethereum, sử dụng mô hình Automated Market Maker (AMM) thay vì sổ lệnh truyền thống.

Đặc điểm chính:

  • Phi tập trung: Không cần tin tưởng vào bên thứ ba
  • Không cần KYC
  • Thanh khoản được cung cấp bởi các nhà cung cấp thanh khoản (Liquidity Providers - LPs)
  • Sử dụng công thức x*y=k để định giá tài sản
  • Phí giao dịch: 0.3% (có thể thay đổi với Uniswap v3)

2. Kiến Trúc Hệ Thống

Các thành phần chính:

  • Factory Contract: Tạo và quản lý các pair contract
  • Pair Contract: Quản lý pool thanh khoản cho từng cặp token
  • Router Contract: Xử lý logic giao dịch phức tạp
  • Interface: Giao diện để tương tác với các contract
  • Uniswap SDK: Bộ công cụ phát triển giúp tương tác với giao thức
  • NonfungiblePositionManager: Quản lý vị thế thanh khoản dạng NFT
  • Quoter: Ước tính kết quả giao dịch mà không cần thực thi
  • Multicall: Gộp nhiều lệnh gọi contract vào một transaction
  • TheGraph: Indexer lấy dữ liệu lịch sử từ blockchain

4. Customize Uniswap Cho Dự Án Startup

4.1. Thay đổi cơ bản

  • Đổi branding (logo, màu sắc, tên) trong frontend
  • Thay đổi phí giao dịch trong contract
  • Thêm các token riêng vào danh sách mặc định

4.2. Nâng cao

  • Thay đổi công thức AMM: Sửa đổi công thức x*y=k trong Pair contract
  • Thêm cơ chế phí mới: Ví dụ phí cho nhà phát triển
  • Tích hợp cơ chế staking: Thưởng cho LP bằng token riêng
  • Cross-chain: Tích hợp với các chain khác như BSC, Polygon
Lưu ý khi customize: Bất kỳ thay đổi nào với core contract cần được audit kỹ lưỡng vì liên quan đến tiền của người dùng.

4.3. Ví dụ thay đổi phí giao dịch

// Trong UniswapV2Pair.sol
uint public constant FEE = 20; // 0.2% thay vì 0.3%

function _mintFee(uint112 _reserve0, uint112 _reserve1) private returns (bool feeOn) {
    address feeTo = IUniswapV2Factory(factory).feeTo();
    feeOn = feeTo != address(0);
    uint _kLast = kLast; // gas savings
    if (feeOn) {
        if (_kLast != 0) {
            uint rootK = Math.sqrt(uint(_reserve0).mul(_reserve1));
            uint rootKLast = Math.sqrt(_kLast);
            if (rootK > rootKLast) {
                uint numerator = totalSupply.mul(rootK.sub(rootKLast)).mul(FEE);
                uint denominator = rootK.mul(5000).add(rootKLast.mul(FEE));
                uint liquidity = numerator / denominator;
                if (liquidity > 0) _mint(feeTo, liquidity);
            }
        }
    } else if (_kLast != 0) {
        kLast = 0;
    }
}

5.2. Ví dụ code thay đổi cơ chế phí

// Trong UniswapV3Pool.sol
function setFeeProtocol(uint8 feeProtocol0, uint8 feeProtocol1) external {
    require(msg.sender == factory);
    require(
        (feeProtocol0 == 0 || (feeProtocol0 >= 4 && feeProtocol0 <= 10)) &&
        (feeProtocol1 == 0 || (feeProtocol1 >= 4 && feeProtocol1 <= 10))
    );
    slot0.feeProtocol = feeProtocol0 + (feeProtocol1 << 4);
    
    // Thêm logic tùy chỉnh
    if (feeProtocol0 == 2) {
        // Xử lý phí đặc biệt 0.02%
        emit FeeChanged(feeProtocol0, feeProtocol1);
    }
}
Lưu ý quan trọng: Khi thay đổi core contract, cần đảm bảo:
  • Không phá vỡ công thức toán học x*y=k
  • Giữ nguyên cấu trúc lưu trữ trạng thái
  • Test kỹ các edge cases với phạm vi giá mới

6. Tích Hợp SDK Vào Ứng Dụng

6.1. Các bước tích hợp cơ bản

// 1. Cài đặt SDK
npm install @uniswap/v3-sdk @uniswap/sdk-core

// 2. Khởi tạo provider và signer
const provider = new ethers.providers.Web3Provider(window.ethereum)
const { chainId } = await provider.getNetwork()
const signer = provider.getSigner()

// 3. Tạo trade instance
const trade = new Trade(
  new Route([pool], tokenIn, tokenOut),
  CurrencyAmount.fromRawAmount(tokenIn, "1000000"),
  TradeType.EXACT_INPUT
)

// 4. Gọi Router contract
const tx = await router.exactInput({
  path: [tokenIn.address, tokenOut.address],
  recipient: walletAddress,
  deadline: Math.floor(Date.now() / 1000) + 60 * 20,
  amountIn: trade.inputAmount.quotient,
  amountOutMinimum: trade.minimumAmountOut(slippage).quotient
}, { gasLimit: 1_000_000 })

6.2. Các tính năng chính của SDK

  • Tính toán swap: amountIn, amountOut, price impact
  • Quản lý thanh khoản: Add/remove liquidity với phạm vi tùy chỉnh
  • Price feeds: Lấy giá từ các pool có sẵn
  • Multicall: Gộp nhiều operations vào một transaction

9. Bảo Mật và Audit

  • Luôn sử dụng phiên bản contract đã được audit
  • Kiểm tra lại mọi thay đổi với core contract
  • Sử dụng thư viện SafeMath để tránh overflow/underflow
  • Triển khai trên testnet trước khi lên mainnet
