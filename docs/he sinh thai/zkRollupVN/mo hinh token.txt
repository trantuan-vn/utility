| -------------------------- | --------------------------- |

| Danh mục chi tiêu      | Mục đích                                |
| ---------------------- | --------------------------------------- |
| Builder Subsidy        | Hỗ trợ gas phí, audit, testnet reward   |
| Retroactive Grant      | Dự án có đóng góp lớn (voting-based)    |
| Staking Reward bổ sung | Thưởng thêm cho người giữ token         |
| Voter Incentive        | Vote DAO đúng lúc sẽ nhận fee/token     |
| Token Buyback / Burn   | Duy trì giá trị ZKVN (DAO tự điều phối) |

4. Token Utility & Fee Integration
| Tính năng                       | Mô tả                                          |
| ------------------------------- | ---------------------------------------------- |
| **Gas Fee bằng ZKVN**           | Mạng hỗ trợ gas bằng ETH hoặc ZKVN             |
| **Staking làm sequencer**       | Đặt cọc ZKVN để tham gia hệ thống Sequencer mở |
| **Voting DAO**                  | Dùng ZKVN để tham gia đề xuất + biểu quyết     |
| **Paymaster ZKVN**              | Smart Wallet có thể dùng ZKVN để chi phí tx    |
| **Discount cho DApp dùng ZKVN** | Trả phí deploy bằng ZKVN được giảm 30%         |
